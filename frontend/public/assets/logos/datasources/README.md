# Data Source Logos

This folder contains logos for various data sources used in the application.

## Usage

Logos can be referenced in React components using:

```tsx
<img src="/assets/logos/datasources/postgresql.png" alt="PostgreSQL" />
```

## Supported Data Sources

Add logos for the following data sources (recommended size: 128x128px or SVG):

### Databases
- `postgresql.png` / `postgresql.svg` - PostgreSQL
- `mysql.png` / `mysql.svg` - MySQL
- `sqlserver.png` / `sqlserver.svg` - Microsoft SQL Server
- `oracle.png` / `oracle.svg` - Oracle Database
- `mongodb.png` / `mongodb.svg` - MongoDB

### Data Warehouses
- `snowflake.png` / `snowflake.svg` - Snowflake
- `bigquery.png` / `bigquery.svg` - Google BigQuery
- `redshift.png` / `redshift.svg` - Amazon Redshift
- `databricks.png` / `databricks.svg` - Databricks

### Cloud Storage
- `s3.png` / `s3.svg` - Amazon S3
- `azure-blob.png` / `azure-blob.svg` - Azure Blob Storage
- `gcs.png` / `gcs.svg` - Google Cloud Storage

### File Formats
- `csv.png` / `csv.svg` - CSV Files
- `excel.png` / `excel.svg` - Excel Files
- `parquet.png` / `parquet.svg` - Parquet Files

## File Naming Convention

- Use lowercase names
- Use hyphens for multi-word names (e.g., `sql-server.png`)
- Prefer SVG format for scalability
- Fallback to PNG with transparent background
